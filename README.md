# Ben's alterations to Perfect Dark PC Port

This branch is intended for the NTSC 1.1/Final ROM only.

Changes include:
* Glass no longer becomes fully opaque at distance (probably most noticable in Villa)
* Moved the "Objective Completed/Failed" message down so it doesn't block the center of the screen
* Stars enabled on Mr. Blonde's Revenge
* Water at the bottom of the chasm on Air Base animated
